FAQ

Questions fréquentes

Est-ce que MOUSLEIME PUB IA publie réellement mes annonces ?

Oui, via les API officielles de Meta (Facebook/Instagram) et TikTok. Vous devez autoriser la connexion à votre compte publicitaire. Si l'API n'est pas configurée, vous pouvez exporter manuellement vos créations.

Comment fonctionne le paiement au Bénin ?

Nous acceptons Mobile Money (MTN, Moov, Celtiis) via CinetPay et KKiaPay, ainsi que les cartes bancaires Visa/Mastercard via Stripe.

Les images et vidéos générées m'appartiennent-elles ?

Oui, vous disposez de tous les droits commerciaux sur les contenus générés depuis votre compte. Vous pouvez les utiliser librement pour vos campagnes.

Puis-je annuler mon abonnement à tout moment ?

Absolument. Pas d'engagement, pas de frais cachés. Vous pouvez passer à la formule gratuite quand vous le souhaitez depuis votre tableau de bord.
